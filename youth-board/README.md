이름 옆 버튼으로 부서를 보내고, 편성된 사람끼리는 `교체` 버튼으로 맞바꿀 수 있습니다.
바꾸면 바로 서버(Firebase `church-71d03` · `youth_board/current`)에 자동 저장되어,
같은 주소를 여는 사람 누구나 같은 편성을 봅니다. 저장 상태는 제목 옆 배지에 표시됩니다.

  그 편성을 서버 기준으로 삼고 싶을 때만 `이 편성을 서버에 반영` 버튼을 누르세요.
